# PROJECT_STATE: Life OS

## Стек и архитектура
- **Тип:** Local-First PWA (HTML5, Vanilla JS, CSS3, IndexedDB, Canvas API).
- **Синхронизация:** Двухконтурная (Яндекс Диск + Google Диск API без прокси).
- **Безопасность:** Изолированная папка appDataFolder, локальные снимки SNAPSHOT_PRE_SYNC, человеческие алерты сбоев.

## Завершенные обновления синхронизации:
- [x] Добавлен Google Диск как полноправный провайдер с прямой поддержкой CORS.
- [x] Внедрена система понятных человеческих ошибок вместо сухих кодов (Actionable Errors).
- [x] Добавлена кнопка «Пересоздать файл в облаке» для устранения битых облачных секторов (File IO failure).
- [x] Создана очередь отложенной синхронизации (Offline Queue) при отключении сети.
- [x] Автоматический локальный слепок базы перед каждым сетевым слиянием.
