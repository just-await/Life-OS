# PROJECT_STATE: Life OS

## Стек и архитектура
- **Тип:** Local-First PWA (HTML5, Vanilla JS, CSS3, IndexedDB, Canvas API).
- **Синхронизация:** Двухконтурная (Яндекс Диск через защищенный шлюз Cloudflare Worker + прямой Google Drive API).
- **Безопасность:** XSS-Shield для системных окон, строгая валидация входящих ссылок в viral.js, асинхронный мост IndexedDB против сбросов кэша на iOS Safari.
