# PROJECT_STATE: Life OS

## Стек и архитектура
- **Тип:** Local-First PWA (HTML5, Vanilla JS, CSS3, Canvas API).
- **Стиль:** Необрутализм (бумажная слоновая кость, благородный эспрессо, четкие чернила 2px).
- **Хранилище:** Двухуровневое (localStorage + IndexedDB vault).
- **Синхронизация:** Приватная через Яндекс Диск API (LWW + счетчики ревизий).
